# 주차 요금 계산기 프로그램 스펙 (SPEC)

## 1. 기술 및 파일 구성
- **Language**: Python 3.x
- **Framework**: Flet (GUI Library)
- **File Structure**:
  - `SPEC.md`: 동작 규칙 및 테스트 케이스 정의
  - `calculator.py`: 요금 계산 로직 (UI 코드 포함 금지, 순수 로직만 담당)
  - `main.py`: Flet 기반 GUI 화면 및 이벤트 처리
  - `test_calculator.py`: 계산 로직 검증을 위한 테스트 파일 (실행 시 통과/실패 수 출력)

## 2. 동작 규칙

### 2.1 요금 계산 로직
- **입력 형식**: 24시간제 `HH:MM` 형식 (예: 09:30, 23:50)
- **주차 시간 계산**: 
  - 입차 시각과 출차 시각 사이의 총 소요 시간을 계산한다.
  - **제약 사항**: 반드시 `출차 시간 > 입차 시간`이어야 한다. (출차 시간이 입차 시간보다 같거나 빠를 경우 에러 처리)
- **요금 산정**:
  - **무료 시간**: 최초 30분까지는 0원.
  - **추가 요금**: 30분 초과 시점부터 **10분당 500원**을 부과한다.
  - **올림 처리**: 10분 미만의 잔여 시간이 발생할 경우, 이를 **10분으로 간주하여 올림 처리**한다.
    - *예: 31분 주차 시 -> (31-30)=1분 발생 -> 10분으로 올림 $\rightarrow$ 500원*
    - *예: 40분 주차 시 -> (40-30)=10분 발생 $\rightarrow$ 500원*
    - *예: 41분 주차 시 -> (41-30)=11분 발생 $\rightarrow$ 20분으로 올림 $\rightarrow$ 1,000원*
- **최대 요금**: 1회 계산 시 최대 요금은 **20,000원**을 초과할 수 없다.

### 2.2 입력 유효성 검사 (Validation)
- **빈 입력**: 입차 또는 출차 시간이 비어있으면 `"모든 시간을 입력해주세요."` 메시지 표시.
- **형식 오류**: `HH:MM` 형식이 아니거나 숫자가 아닌 경우 `"올바른 시각 형식(HH:MM)을 입력하세요."` 메시지 표시.
- **범위 오류**: 시(0-23) 또는 분(0-59)이 범위를 벗어난 경우 `"유효한 시각을 입력하세요."` 메시지 표시.
- **논리 오류**: 출차 시간이 입차 시간보다 같거나 빠른 경우 `"출차 시간은 입차 시간보다 뒤여야 합니다."` 메시지 표시.

### 2.3 데이터 및 목록 관리
- **목록 추가**: 계산 성공 시 `[입차, 출차, 주차 시간, 요금]` 정보를 리스트에 누적하여 화면에 표시한다.
  - **주차 시간 표시 포맷**: `H시간 M분` (예: `1시간 10분`, `0시간 45분`)
- **항목 삭제**: 각 기록(Card) 옆에 **[삭제]** 버튼을 배치한다. 버튼 클릭 시 해당 항목이 즉시 제거되며, 하단의 '오늘 총 합계'가 실시간으로 재계산된다.
- **전체 삭제**: **[오늘 기록 전체 삭제]** 버튼을 통해 목록과 총 합계를 모두 초기화한다.

## 3. 화면 구성 (UI)

- **테마**: Flet Light Theme 적용
- **레이아웃**:
  - **상단 (Input Area)**: 입차 시간 TextField, 출차 시간 TextField, **[계산]** 버튼
  - **중앙 (List Area)**: 계산된 기록들을 보여주는 ListView (각 항목은 Card 형태로 시각화)
  - **하단 (Summary Area)**: 
    - **'오늘 총 합계: [금액]원'** 표시
    - **[오늘 기록 전체 삭제]** 버튼
- **데이터 포맷**: 금액 표시 시 천 단위마다 쉼표(,)를 삽입한다. (예: `12,500원`)
- **에러 피드백**: 
  - **입력 오류(형식/범위/논리)**: 해당 `TextField`의 `error_text` 속성을 사용하여 즉각적인 시각적 피드백을 제공한다.
  - **기타 시스템 오류**: `SnackBar`를 통해 알림을 전달한다.

## 4. 테스트 케이스

### 4.1 정상 케이스 (경계값 포함)
- **무료 구간 경계**: 
  - 30분 주차 (예: 09:00 ~ 09:30) $\rightarrow$ 요금: 0원
  - 31분 주차 (예: 09:00 ~ 09:31) $\rightarrow$ 요금: 500원
- **10분 단위 경계**:
  - 40분 주차 (예: 09:00 ~ 09:40) $\rightarrow$ 요금: 500원
  - 41분 주차 (예: 09:00 ~ 09:41) $\rightarrow$ 요금: 1,000원
- **최대 요금 경계**:
  - 10시간 주차 (예: 09:00 ~ 19:00) $\rightarrow$ 요금: 20,000원
  - 24시간 주차 (예: 09:00 ~ 익일 09:00) $\rightarrow$ 요금: 20,000원 (한도 적용)

### 4.2 에러 케이스
- 빈 칸 입력 시 $\rightarrow$ `"모든 시간을 입력해주세요."`
- `25:60` 또는 `abc:def` 입력 시 $\rightarrow$ `"올바른 시각 형식(HH:MM)을 입력하세요."` 또는 `"유효한 시각을 입력하세요."`
- `14:00` 입차, `12:00` 출차 시 $\rightarrow$ `"출차 시간은 입차 시간보다 뒤여야 합니다."`
- `14:00` 입차, `14:00` 출차 시 $\rightarrow$ `"출차 시간은 입차 시간보다 뒤여야 합니다."`
