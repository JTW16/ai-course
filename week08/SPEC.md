# 주차 요금 계산기 프로그램 스펙 (SPEC)

## 1. 개요
Python Flet을 사용하여 입차 및 출차 시각을 기반으로 주차 요금을 계산하고, 당일 수납 합계를 관리하는 단일 창 프로그램.

## 2. 주요 기능
### 2.1 요금 계산 로직
- **입력 방식**: 24시간제 '시:분' 형식 (예: 09:30)
- **입력 제약**: 출차 시간은 반드시 입차 시간보다 뒤여야 함 (단, 자정 통과 시 예외 적용)
- **무료 시간**: 처음 30분까지 무료
- **추가 요금**: 30분 이후부터 10분당 500원 (10분 미만의 나머지도 10분으로 올림 처리)
- **최대 요금**: 하루 최대 20,000원 제한
- **자정 통과 처리**: 출차 시간이 입차 시간보다 작을 경우, 출차를 다음 날로 간주하여 계산 (예: 23:00 입차, 01:00 출차 -> 2시간 주차)

### 2.2 기록 관리
- **목록 추가**: 계산 시마다 [입차, 출차, 주차 시간, 요금] 정보를 리스트에 누적
- **항목 삭제**: 각 기록 옆에 삭제 버튼을 배치하여 개별 항목 제거 가능. 삭제 시 '오늘 총 합계'는 즉시 재계산됨
- **전체 삭제**: 오늘 기록을 한 번에 초기화하는 '오늘 기록 전체 삭제' 버튼 제공
- **합계 계산**: 항목이 추가되거나 삭제될 때마다 실시간으로 '오늘 총 합계' 업데이트

### 2.3 UI/UX 요구사항
- **레이아웃**:
  - 상단: 입력부 (입차 시간 TextField, 출차 시간 TextField, 계산 버튼)
  - 중앙: 기록 목록 (ListView 형태)
  - 하단: 오늘 총 합계 표시 및 전체 삭제 버튼
- **데이터 포맷**: 금액 표시 시 천 단위마다 쉼표(,) 삽입 (예: 12,500원)
- **테마**: Flet Light Theme 적용

## 3. 기술 스택
- Language: Python
- Framework: Flet
